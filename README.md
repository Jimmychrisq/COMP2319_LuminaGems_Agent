# COMP2319_LuminaGems_Agent

An intelligent e-commerce AI agent designed for a fictional jewelry store, "Lumina Gems". It helps users find products based on their budget and style, answers store policy questions using RAG, and securely processes refunds with human-in-the-loop approval. Built for COMP2319 Comprehensive Project.
